# Changelog

All notable changes to PathParity are documented here.

## [0.1.0] - 2026-09-28

### Added

- Read-only directory scanning for Windows, macOS, and Linux portability hazards.
- Manifest scanning for logical paths that cannot be created on the current operating system.
- Stable text/JSON reports and clean/review/block exit codes.
- Checks for reserved names, invalid characters, trailing dot/space names, long paths, case
  collisions, Unicode normalization collisions, and symlinks.
- MIT license, security policy, contribution guide, examples, tests, and cross-platform CI.
